**Tech Stack:** TypeScript, DOM, Vite, Fastify, PostgreSQL, Node test, browser CUA.
**Spec:** docs/superpowers/specs/2026-11-16-t13-probe-ui-design.md

## Global Constraints
Default off; no free text, real credentials, real provider calls, ordinary-member grants, production mounting or edits to #79 Settings/Home/local-main. Coordinate build/GUI exclusivity with T12. Existing files are hardlinked snapshot: unlink before changes.

- Malicious label/output must render only as plain text.

- Startup without complete explicit assets/config must fail closed.
