# T13 SSE transport stage implementation plan

Goal: exercise the existing provider turn coordinator through a bounded HTTP SSE adapter and the existing AgentTransport callbacks, without enabling a provider in the product.
Architecture: add an explicitly registered Fastify adapter with mandatory session/CSRF dependencies; preserve default-deny app wiring. Add transport model selection and optional CSRF acquisition without changing AgentTransport methods. Provider output is untrusted tool-call data, never approval or execution.

- [x] RED/GREEN external abort coverage on the coordinator, including cancellation before authority settles; keep capacity reserved for uncooperative dependencies.
- [x] RED/GREEN opt-in HTTP routes: cookie identity, CSRF, request allowlist, finite SSE output, backpressure/disconnect, single terminal done/error. Use only injected mock provider, no external calls.
- [x] RED/GREEN browser model/CSRF headers and strict event projection; absent usage stays unknown and truncated tool arguments fail closed.
- [x] Run coordinator/transport/route tests, strict targeted types and independent review, then publish draft only.

Non-goals/blockers: T12 secret/config/budget adapter, durable usage reservation/settlement, real model credentials and permitted real-model cases, native editor UI hookup, and T14 approval/journal execution. No app.ts mount or config/schema migration in this stage; do not mark T13 complete.
