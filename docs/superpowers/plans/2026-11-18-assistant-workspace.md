# 助手协作区实施计划

**设计：** `docs/design/assistant-workspace.md`，用户已确认实施。

**目标：** 在 DOCX/XLSX 使用同一个输入区选择 Office、内置 harness 或频道助手，提供可核对的任务状态和原有交付操作。

**实现：** browser-host coding client 复用 SSE 执行并记录会话内任务；workspace controller 管理显式目标和提交；Web React 协作区提供身份、任务和管理入口。编辑器通过共享 UI 契约注入面板及发送拦截，聊天保持挂载。原生权限、模型工具及频道持久任务契约保持原有边界。

- [x] coding client：先增加真实 SSE 行为测试，覆盖显式对象、发送时冻结模型、任务完成、失败及取消待核对；再实现任务订阅及直接运行接口。
- [x] workspace controller：测试 Office 不拦截、正确路由、离线/暂停拒绝、失败保留输入语义、附件/Skills/选区不隐式外发；实现目标绑定与通知。
- [x] React 协作区：测试视图切换、来源、任务状态和选择对象；实现对话/助手/任务视图、接入管理与结果入口。
- [x] DOCX/XLSX：注入 workspace 契约，在手动提交处先处理显式委派，发送成功才清理同一草稿，普通 Office 与队列沿用原流程；模型选择器只渲染模型。
- [x] 验证：运行新增测试、既有 coding/assistant/channel/交付回归；运行 DOCX/XLSX/Web 类型检查及两种编辑器构建。真实服务和模型未执行的部分如实记录。

限制：内置状态保存在当前编辑器会话，刷新不能恢复运行。取消 SSE 请求不能证明远端执行已停止，须显示结果待核对。频道状态采用服务端快照。运行已配置不等同真实 harness 验收。
