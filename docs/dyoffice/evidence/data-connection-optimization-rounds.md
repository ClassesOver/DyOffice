# 数据连接交互优化：20 轮进度

从「优化20轮」目标建立后计数。每轮对应一个可验证的用户行为，按当前代码和验证结果记账。现有可见范围仍需保存才生效；数据库账号的只读校验始终开启。

| 轮次 | 改动 | 验证 |
| --- | --- | --- |
| 1 | 目录读取失败时在可见范围内说明，并提供「测试连接并查看原因」。 | 组件测试验证权限错误能进入连接诊断，无配置写入。 |
| 2 | PostgreSQL、MySQL、StarRocks 新目标默认普通连接；未配置数据库目标时直连也使用普通连接。已保存的 TLS 目标继续使用 TLS。 | 连接策略单测覆盖三种数据库和明确开启 TLS；真实 PostgreSQL 通过默认直连和白名单回归。真实 StarRocks 默认直连到达只读校验并正确拒绝高权限账号。 |
| 3 | 无法读取目录时显示具体原因；缺凭据或凭据未保存时可以跳回连接设置。 | 组件测试验证跳转保留未提交的凭据，不读取未保存连接。 |
| 4 | 在已选表里标记未开放目录中的表，并说明它们保存后仍不可见。 | 组件测试验证 PostgreSQL 无目录前缀的表按 `public` 判断；移除目录限制后标记消失，两张表继续保留。 |
| 5 | 数据连接页签可以用方向键和 Home、End 切换，Tab 只停在当前页签。 | 组件测试验证键盘切换、首尾循环、焦点与选中页签同步。 |
| 6 | 目录搜索无结果时可一键清除搜索，恢复目录列表并保留当前展开的表。 | 组件测试验证不重新请求数据库，焦点回到搜索框。 |
| 7 | 标记当前浏览的目录，切回最近浏览的目录时直接复用表列表。 | 组件测试验证切回无需再次请求，手动重新读取会清除缓存。缓存只用于当前连接版本。 |
| 8 | 保存可见范围后恢复正在浏览的目录和表搜索。 | 组件测试验证刷新请求使用新版本，已保存的勾选与搜索条件保留。 |
| 9 | 连接已保存但列表刷新失败时，当前连接仍可继续测试。 | 组件测试验证只写入一次、随后连接测试通过，回列表时仍显示重试提示。 |
| 10 | 保存前校验连接地址，在凭据字段旁说明协议、服务器、账号密码、数据库名或参数问题。 | 组件测试验证协议不匹配、缺少数据库名时不发保存请求，草稿保留，提示不回显秘密。 |
| 11 | 从可见范围返回补填缺失凭据时，直接打开并聚焦连接地址输入框。 | 组件测试验证切换凭据操作和焦点。 |
| 12 | 连接测试期间显示「正在测试连接…」，结束时显示结果。 | 组件测试使用延迟响应，验证等待提示在结果到达时消失。 |
| 13 | 表列表支持「只看已选表」，可同时按表名搜索。 | 组件测试验证隐藏未选表、搜索空态和保留其他目录的勾选。 |
| 14 | 可单独恢复已保存的目录和表。 | 组件测试验证恢复不发出写请求，保留未保存的名称和高级配置，并区分不限范围与空清单。 |
| 15 | 达到 256 项后停止添加，仍可取消勾选或移除已选项。 | 组件测试验证选满后禁用未选表，取消勾选后可继续添加。 |
| 16 | 读取失败可以原地重试；读取表失败时只重试该目录。 | 组件测试验证请求顺序与勾选保留。 |
| 17 | 展开的目录显示已读取表中的勾选数量。 | 组件测试验证按表名搜索不会改变目录计数。 |
| 18 | 浏览表时可直接将当前目录设为唯一允许的目录。 | 组件测试验证切换到指定目录并勾选当前目录，同时保留已选表。 |
| 19 | 手工粘贴范围时去重，超过上限在保存前提示。 | 组件测试验证 257 个不同表名不发出写请求，重复表名只保存一次。 |
| 20 | 目标不支持 TLS 时，直接指向全局配置的「使用 TLS」选项。 | 组件测试验证提示文字；连接策略回归验证三种数据库默认走普通连接，明确配置的 TLS 仍生效。 |

最终核验：数据连接及相关设置 100 项组件测试、7 项后端源策略测试通过，前端构建通过。Shell 类型检查仍有 Word 模块原有的 `DesktopFilesApi` 类型错误。

真实 StarRocks 复测见[客户验收记录](starrocks-customer-acceptance.md)；业务库选表仍需使用专用只读账号。
