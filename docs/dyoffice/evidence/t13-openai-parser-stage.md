# T13 pure OpenAI-compatible SSE parser stage

Base: `10793fcdc93f033c33a886434be35f3a6d83733d`. This independent increment adds
only a pure parser, tests and this evidence. It does not depend on mounting the
HTTP adapter in #68, change T12 or T14, perform fetches, hold keys or execute tools.

## Contract and deliberate restrictions

`parseOpenAiChatStream(AsyncIterable<Uint8Array>, options)` produces the existing
TurnEvent union. It requires valid UTF-8 and an SSE `[DONE]` frame; accepts one
choice; rejects invalid JSON/provider errors with a fixed message. Tool argument
fragments are buffered under byte/call limits. All completed tools are validated
before any candidate is emitted. Candidate IDs remain untrusted provider IDs,
not T14 command IDs. Tool-name fragments concatenate exactly: provider-specific
cumulative-name resends are not guessed or rewritten in this strict subset.

A finish marker is immutable and may appear once. A length-truncated tool turn
never emits tool candidates, even if its partial JSON happens to parse. A later
stop marker cannot override length. Missing usage remains absent, not zero;
reported counts must be nonnegative safe integers. Deltas can arrive before a
later protocol error, but incomplete tools cannot execute because this parser
neither exposes them early nor executes any tools at all.

Default input budget is 8 MiB, frame/tool-argument limits 256 KiB and tool count
64. Signal cancellation is checked for stalled reads and between yielded events,
including multiple events decoded from one frame. Iterator cleanup is attempted
without awaiting an uncooperative source forever. The eventual transport must own
absolute deadlines, underlying network abort, and admission accounting until real
network operations settle; parsing alone is not an egress implementation.

## T12 and real-provider blockers

At the reviewed #52 configuration interface, public settings return metadata and
secret decryption is confined to administrator config checking/rotation. There
is no ordinary-user, model-scoped secret-use callback for T13. Do not reuse admin
secret access or widen RLS to enable provider calls. A trusted resolver must bind
session authority, enabled configuration ID/revision/kind, and restricted egress
inside the server, without returning keys or provider routing to the browser.

Existing desktop provider functions use process-global aiFetch/rescue retry, so
this stage does not silently call them as a tenant-safe server gateway. Pinned
streaming egress, a scoped secret callback, durable budget reservation/settlement,
provider-specific compatibility, client-approved real model cases, editor wiring
and T14 approval remain unaccepted. No full T13 completion or real-model success
is claimed. Full monorepo suites are outside this standalone parser validation.
