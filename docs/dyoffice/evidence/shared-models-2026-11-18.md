# SaaS 共享模型接入验证

管理员在全局配置维护服务商、模型、API 密钥及接口地址。所有已授权账号直接使用共享模型，界面不展示配置版本；内部修订号只承担并发更新及撤销检查。

## 实现与边界

- 本地账号服务默认启用共享模型网关，直接读取保存的全局配置，无需外部 profile 文件或个人额度。
- 当前共享调用实现 OpenAI-compatible Chat Completions，DeepSeek 已实测；其他原生协议未宣称通过。
- 新增迁移 0034，派发记录按部署、账号、会话和 turn 绑定。派发前持久化，重复请求不再发送；凭据只在服务器解密及发送。
- 保留显式 profile 模式的原有预算行为，不改变既有账本或额度。
- 配置页增加“测试连接”，仅管理员可执行；未保存更改时要求先保存。保留原 GenOffice 编辑器 AI 面板，无首页独立聊天。

## 验证

- PostgreSQL 17 独立测试库：5 个共享网关集成测试通过，覆盖跨账号目录、保存即时生效、停用、真实 SQL 凭据读取＋模拟 HTTPS、重放拒绝、私网拒绝、CSRF、数据库直接读取拒绝、TLS 等待时配置撤销及管理员连接测试。
- 原个人预算接入及动态 profile：6 个测试通过。
- 配置界面及客户端、编辑器状态：48 个测试通过。
- Web 及服务器类型检查通过，首页构建通过。
- 本地现有账号：共享目录 HTTP 200，包含 1 个可用模型；现有 DeepSeek 的真实简短连接测试 HTTP 200，结果成功。未输出密钥、认证信息或模型正文。
- Firefox：真实共享模型目录＋隔离 DOCX 文件加载；原功能区“AI 助手”打开原侧栏，可见模型选择，不再提示没有模型；无页面脚本异常。首页无独立聊天入口，全局配置无版本号。

真实文档内容未修改。数据库已应用 0034 并按既有运行角色重新授权，用户密码未改变。


## 配置体验调整

- 全局配置沿用头像弹窗，左侧固定“AI 模型 / 生图、媒体与搜索”，右侧内容独立滚动。
- 常用设置按服务商、模型、API Key、Base URL、启用顺序横向排列；右上角集中连接测试与保存。
- 服务配置改为下拉选择，保留多配置、跨分类草稿、密钥清理、并发冲突与写入不确定保护。
- 名称、用途、默认项及删除收进“更多设置”；加密主密钥维护收进“高级维护”，明确不会更换服务商 API Key。
- 未配置媒体服务时按五种用途提供直接配置入口；本次完成配置管理，媒体与搜索的实际执行通路未宣称已经接通。
- 最新前端配置与客户端测试 46 项通过，共享网关及原预算接入回归 11 项通过。Firefox 验证两组配置切换、原 Word AI 助手模型目录及零脚本异常；首页结构保持不变。
