# 频道分享与后台文档读取

首页左下角账号菜单的「个人工作区」分组提供「频道分享」和「后台任务」，与「个人设置」同级。创建频道不要求选择文件，也不要求打开编辑器。可创建多个频道，签发 DSH 授权 Token、暂停协作或移除成员。

需要后台读取时，在频道详情选择自己的 DOCX、XLSX、PPTX 或 PDF 并开启「允许后台读取已保存版本」。每个频道绑定一个文件，已有绑定不能改成另一个文件；需要其他文件时创建另一个频道。当前支持这四种格式的保存版文字提取和问答，不包含图片、排版、未保存内容或修改操作。

使用 DSH Web 时，可安装右侧栏插件查看当前频道文档的最新保存版文字和任务进度。在频道启用后台读取后，选择 Token 有效期并生成一个授权 Token；将该 Token 粘贴到 DSH 右侧栏即可连接，不需要邀请、申请、审批或兑换。Token 仅保存在 DSH 服务端，过期时间可在 DyOffice 设置；签发者登录会话过期或注销后需重新签发。[插件安装与连接](../../integrations/dsh-dyoffice/README.md)

## 部署

使用 `apps/web/server/index.mjs` 的本地账号入口及现有数据库迁移/角色初始化流程，应用迁移 `0037_assistant_background.sql`。配置：

```bash
DYOFFICE_ASSISTANT_CHANNELS=on
DYOFFICE_ASSISTANT_BACKGROUND=on
DYOFFICE_WORKER_DATABASE_URL=postgresql://<受限worker角色>@<数据库地址>/<数据库>
```

同时需要现有账号、业务数据库、对象存储、配置密钥和模型网关配置。调度库与账号库必须连接同一数据库和 schema。使用项目 `db/roles.ts` 的 worker 角色授权流程；不应使用数据库所有者或超级用户。服务启动会核对角色及数据库一致性，后台开关默认关闭，关闭时不接收新后台任务。频道详情会显示部署尚未开启后台执行。

调度器在 Web 服务内运行，无需 DSH 插件、DSH 机器上的 genoffice 或独立连接器。队列持久保存在 PostgreSQL，多实例竞争领取，单实例同一时刻执行一个任务；同频道遵守 Office 执行并发约束。空闲轮询逐步延长至 5 秒，执行期间每 5 秒续租，租约 30 秒。

## 成员提交和查询

DSH 直接使用授权 Token 作为成员凭证，通过 `GET /api/v1/assistant-channels/member` 获取自己的频道和成员 ID，再调用成员 API。成员 API 使用 `Authorization: Bearer <memberToken>`，不使用所有者 Cookie。自动控制既有 DSH Web/桌面会话不属于此接口的能力范围。

向 `POST /api/v1/assistant-channels/members/<memberId>/actions` 提交：

```json
{
  "requestId": "<本次请求的UUID，重试时保持相同>",
  "conversationId": "<频道UUID>",
  "to": "office",
  "action": {
    "kind": "delegate",
    "instruction": "列出预算总额和单位。",
    "execution": "saved-revision"
  }
}
```

DSH 插件只需私密保存授权 Token。每次连接时先使用该 Token 请求 `/member`，从响应的 `member.membershipId` 和 `conversationId` 读取身份；不要要求用户另行提供 ID 或第二个凭证。每次 HTTP 请求都检查状态码，非 200 立即停止并报告失败步骤和真实状态。

提交返回 `taskId`。通过 `GET /api/v1/assistant-channels/members/<memberId>/tasks/<taskId>` 查询同一任务的 `state`、`summary` 和 `savedRevision`，最终明确输出 `taskId`、`savedRevision`、`state` 和 `summary`，不把失败、取消或结果待核对表述为成功。省略 `execution` 的现有任务仍由在线浏览器处理。

提交事务冻结当时的保存版本、SHA-256 和大小；之后保存新版本不会改变该任务读取的版本。四格式输入最大 10 MiB，提取最多 24,000 字符，输出最多 16 KiB UTF-8。XLSX 使用已保存缓存值，不重算公式、不访问外链；无缓存的公式可能以文字呈现。PDF 扫描件和图片不进行 OCR。模型使用所有者可用的默认模型及现有凭据、额度和派发链，工具列表为空。文本截断信息会传入模型，回答要求说明保存版本及摘录范围。

## 查询、取消和恢复

账号菜单中的「后台任务」可查看跨文档记录、版本、状态和结果，进入来源频道或打开文档，也可取消尚未结束的任务。文档内任务卡和成员查询使用同一任务 ID。关闭标签页不会注销会话，因此可以继续后台执行；主动退出登录、会话过期、移除成员、暂停频道、关闭后台读取、删除文件或取消任务后，服务重新核对授权，禁止发布迟到正文结果。

队列中的封存凭证只供服务恢复原会话并重新校验权限，不直接赋予文件权限；结算或清理后清除。服务重启可继续领取尚未领取的任务。服务正常关停会中止对象读取、解析和模型调用，并等待当前领取与心跳完成后再关闭连接池。编辑器重新连接或关闭不会中断后台任务。已领取且租约丢失的运行任务进入「结果待核对」，不会自动重跑；尚未开始的过期领取会取消。用户应先核对结果再决定是否重新提交。

停用时先停止接收新任务：可逐频道关闭后台读取并等待取消完成，或保留已启用实例排空队列，再关闭服务总开关。直接关闭全部调度实例会保留尚未领取的队列；重新启用后才会继续核验和清理。保留任务记录，不通过删除队列表停用功能。升级前按既有流程备份数据库；不要改写已应用迁移的校验和。

测试范围与待验收项见 [后台任务验证记录](evidence/assistant-background-2026-11-19.md)。
